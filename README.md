# Crypto Paragraph Dashboard (Vercel frontend)

Static frontend for the crypto price monitoring bot. Connects to the alwaysdata backend API.

## Features
- RTL Persian UI with dark theme
- Monitor management (add/delete/toggle)
- Message template editor
- Real-time preview
- Vercel-ready (static site)

## Setup on Vercel
1. Push this repo to GitHub
2. Import in Vercel → Deploy
3. In the dashboard, enter your API URL

## File Structure
```
├── index.html          # Main page
├── vercel.json         # Vercel config
└── assets/
    ├── style.css       # Dark theme styles
    └── dashboard.js    # Frontend logic
```
